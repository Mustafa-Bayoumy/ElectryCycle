# Electrycle

Electrycle is a React-based web application developed as a graduation project for the Digital Egypt Pioneers Initiative (DEPI) React Frontend Track.

The platform helps users recycle their old electronic devices by allowing them to schedule a pickup or choose a trusted drop-off location. Its goal is to make electronic waste recycling more convenient while encouraging environmentally responsible disposal practices.

## Project Overview

Electronic waste continues to grow every year, while many unused devices remain stored in homes or are disposed of incorrectly. Electrycycle provides a simple digital solution that connects users with a convenient recycling process.

Users can schedule a recycling appointment, select their preferred collection method, and manage the process through an intuitive and responsive interface.

## Features

- Schedule a recycling appointment
- Choose between home pickup and drop-off locations
- User authentication
- Responsive design for desktop and mobile devices
- Dark and light theme support
- FAQ section
- Contact page

## Technology Stack

- React
- React Router
- JavaScript (ES6+)
- HTML5
- CSS3
- GitHub Pages for deployment

## Getting Started

### Clone the repository

```bash
git clone https://github.com/Mustafa-Bayoumy/Electrycycle.git
```

### Navigate to the project directory

```bash
cd Electrycycle
```

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm start
```

The application will be available at:

```
http://localhost:3000
```
